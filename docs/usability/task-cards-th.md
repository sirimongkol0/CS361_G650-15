# Task cards — PCSMS usability test

> อ่านเฉพาะ “สถานการณ์” และ “เป้าหมาย” ให้ผู้ใช้ฟัง  
> ห้ามอ่านขั้นตอนหรือชี้ปุ่ม

---

## TC1 — Student / Public

**สถานการณ์**
> “คุณเป็นนักศึกษาที่ต้องการทราบว่าหลักสูตรมีความร่วมมือกับหน่วยงานหนึ่งอย่างไร ขอให้ค้นหาหน่วยงานนั้น เปิดข้อตกลงที่เกี่ยวข้อง เปิดกิจกรรมที่เชื่อมโยง และดาวน์โหลดไฟล์ข้อตกลงถ้ามี”

**เป้าหมาย**
- หาหน่วยงานได้
- เปิดข้อตกลงที่เกี่ยวข้องได้
- เปิดกิจกรรมที่เชื่อมโยงได้
- ดาวน์โหลด PDF ได้ หรืออธิบายได้ว่าทำไมไม่มีไฟล์

**จุดเริ่มต้น:** `/dashboard/public` หรือ `/login` ด้วยบัญชี student  
**สำเร็จเมื่อ:** ครบทั้ง 4 ข้อข้างต้นโดยไม่ได้รับความช่วยเหลือ

---

## TC2 — Staff / Coordinator

**สถานการณ์**
> “คุณเป็นเจ้าหน้าที่หลักสูตร ต้องการบันทึกกิจกรรมใหม่ที่จัดร่วมกับหน่วยงานหนึ่ง และเชื่อมกับข้อตกลงที่มีอยู่ จากนั้นตรวจสอบว่ารายการนี้ปรากฏในหน้าสาธารณะ”

**เป้าหมาย**
- สร้างกิจกรรมใหม่
- เลือกหน่วยงานให้ถูกต้อง
- เชื่อมข้อตกลงที่มีอยู่
- บันทึกและเผยแพร่
- ตรวจสอบว่าเห็นในหน้าสาธารณะ

**จุดเริ่มต้น:** `/dashboard/staff` หรือ `/dashboard/coordinator`  
**สำเร็จเมื่อ:** กิจกรรมถูกสร้าง เชื่อมความสัมพันธ์ถูกต้อง เผยแพร่แล้ว และเห็นในหน้าสาธารณะ

---

## TC3 (optional) — Feedback / Improvement

**สถานการณ์**
> “คุณต้องการแจ้งความคิดเห็นเกี่ยวกับกิจกรรมหนึ่งให้หน่วยงานที่เกี่ยวข้องทราบ และต้องการติดตามว่าความคิดเห็นนั้นได้รับการตอบกลับหรือยัง”

**เป้าหมาย:** ส่งความคิดเห็น → ดูสถานะ → (สำหรับเจ้าหน้าที่) ตอบกลับ/ตรวจสอบ → บันทึกการปรับปรุง

---

## TC4 (optional) — Import

**สถานการณ์**
> “คุณมีไฟล์ข้อมูลความคิดเห็นจำนวนหนึ่ง ต้องการนำเข้าสู่ระบบ ตรวจสอบตัวอย่างก่อนยืนยัน และตรวจสอบผลลัพธ์หลังนำเข้า”

**เป้าหมาย:** ดาวน์โหลด template → เตรียมไฟล์ → upload → preview → confirm → ตรวจผล
