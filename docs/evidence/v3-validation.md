| ตรวจอะไร | ผลที่ได้ |
|---|---|

## ขั้นตอนที่ `v3-functional.cjs` ทดสอบ (เข้าสู่ระบบจริงทีละบทบาท)

1. ทุกบทบาทเข้าสู่ระบบผ่านหน้าเว็บแล้วไปที่หน้าหลักของตัวเอง รหัสผ่านผิดถูกปฏิเสธ
2. ผู้ใช้ทั่วไปและนักศึกษาเปิดหน้าจัดการไม่ได้ (หน้าเว็บแจ้งไม่มีสิทธิ์ API ตอบ 403)
3. อาจารย์สร้างข้อตกลงฉบับร่างและอัปโหลด PDF ฉบับร่างไม่แสดงสาธารณะ และอาจารย์อนุมัติเองไม่ได้
4. อาจารย์เปิดไฟล์ภายในผ่านลิงก์อายุ 5 นาที
5. เจ้าหน้าที่ตรวจความเกี่ยวข้องกับ CSTU อนุมัติ ตั้งให้มีผล และเผยแพร่ แล้วข้อตกลงแสดงในหน้าสาธารณะ
6. การเปลี่ยนสถานะที่ไม่อนุญาต (มีผล → อนุมัติแล้ว) ได้ 409
7. อาจารย์เพิ่มกิจกรรม กิจกรรมไม่แสดงจนเจ้าหน้าที่เผยแพร่
8. เจ้าหน้าที่เพิ่มข้อมูลการแลกเปลี่ยนให้นักศึกษา เห็นได้เฉพาะนักศึกษาคนนั้นและเจ้าหน้าที่
9. อาจารย์เพิ่มผู้ประสานงานเป็นฉบับร่าง เจ้าหน้าที่แก้ไขและลบได้
10. เจ้าหน้าที่เพิ่มหน่วยงานพร้อมแหล่งที่มาที่ตรวจแล้วและเผยแพร่ แสดงในหน้าสาธารณะ
11. ทุกการเปลี่ยนแปลงข้างต้นอยู่ในประวัติการแก้ไขพร้อมผู้ที่ทำ
12. ออกจากระบบแล้ว token เดิมใช้ไม่ได้

ข้อมูลที่เทสต์สร้างใช้ชื่อขึ้นต้นด้วย `FT-` และลบออกเมื่อจบ
