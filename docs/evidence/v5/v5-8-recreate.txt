## Teardown and the versioned-bucket bug

Command:
  STACK=cs361-v5r ... deploy.sh teardown --yes --purge
Elapsed: 171s

Result:
  All three stacks deleted; Cognito pool deleted; EC2/DB/EIP/secret deleted.
  The retained S3 bucket could NOT be deleted by `aws s3 rb --force` because
  versioning left noncurrent versions and delete markers:
    BucketNotEmpty: You must delete all versions in the bucket.
  Fix: `deploy.sh` now lists and deletes every object version and delete marker
  (bounded loop) before calling delete-bucket. The leftover bucket was purged
  manually with the same logic and then deleted successfully.
