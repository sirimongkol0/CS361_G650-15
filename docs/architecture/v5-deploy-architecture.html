สถาปัตยกรรมการ deploy ระบบ V5

CS361 G650-15 · automation / IaC · CloudFormation 4 stacks + Cognito + Amplify หรือ fallback บน EC2 · Learner Lab us-west-2 · บัญชีปกติ ap-southeast-2

#ขั้นตอนรายละเอียด
1ตรวจและวางแผนdeploy.sh check ตรวจ identity, region, mode และ service probes จากนั้น deploy.sh สร้าง change set ด้วย cloudformation deploy --no-execute-changeset ให้ตรวจก่อน --apply
2Base stack cs361stack.yaml สร้าง VPC, public subnet, security group เปิด 8000/3000 (ไม่เปิด 22), EC2, Elastic IP, S3, Secrets Manager secret, SSM parameter และ IAM ตาม LabMode
3Cognito stackcognito.yaml สร้าง user pool cstu-v5-auth, app client และกลุ่มบทบาท 5 กลุ่ม; เขียน pool/client ID ลง SSM; provision_cognito.py สร้างผู้ใช้ทดสอบ
4Amplify หรือ fallbackถ้ามี GITHUB_TOKEN_SECRET_ARN ให้ amplify.yaml สร้าง app WEB_COMPUTE และ branch main; ถ้าไม่มีให้ deploy.sh frontend --apply สร้าง Next.js container บน EC2 พอร์ต 3000
5Backenddeploy.sh backend อัปโหลด tarball ขึ้น S3, อ่าน SSM + Secrets Manager, เขียน .env สิทธิ์ 600, build/restart container และตรวจ /api/v1/health
6Seeddeploy.sh seed --yes ลบข้อมูลใน cstu_demo แล้วใส่ข้อมูลสมมติ; ต้อง backup ก่อนถ้ามีข้อมูลเดิม
7Backup stackbackup.yaml สร้าง SNS topic, SSM document, EventBridge Scheduler rate(1 day) และ CloudWatch alarm; backup รัน pg_dump ขึ้น S3 และ publish metric
8ตรวจผลdeploy.sh status ตรวจ API health และ frontend; เก็บ SSM command ID, stack outputs และผล backup เป็นหลักฐาน

เปลี่ยนใน V5

  • CloudFormation 4 stack + change set + drift
  • Cognito เป็น IaC (pool/client/groups)
  • SSM Parameter Store + Secrets Manager
  • Amplify ถ้ามี token; fallback frontend บน EC2
  • Backup อัตโนมัติ + SNS + CloudWatch alarm
  • CI ตรวจ cfn-lint/cfn-guard

ข้อจำกัด Learner Lab

  • เฉพาะ us-east-1 / us-west-2
  • สร้าง IAM role/user/policy ไม่ได้
  • ใช้ LabRole + LabInstanceProfile
  • GitHub OIDC ถูกปฏิเสธ (#122 ปิด)
  • Amplify build SSR ยังไม่ยืนยัน
  • session หมดอายุ → EC2 หยุด

ยังไม่ทำใน V5

  • Multi-AZ, load balancer, Auto Scaling
  • HTTPS ระหว่าง frontend กับ API
  • rollback อัตโนมัติของ backend
  • secret rotation อัตโนมัติ
  • workflow deploy backend ใน repo
  • production SLA / load test

Base stack, Cognito, backend, fallback frontend, backup/restore/alert และ drift ถูกทดสอบใน Learner Lab เมื่อ 8 พฤศจิกายน 2026; Amplify stack/build ยัง N/A เพราะไม่มี token และ teardown + recreate ยัง TBD. หลักฐานอยู่ใน docs/evidence/v5-validation.md. คำสั่งทั้งหมดใช้ infra/new-account/deploy.sh และไม่ใช้ SSH; teardown --yes --purge ใช้เมื่อต้องการลบ S3/Cognito ที่ retain เพื่อ recreate.
