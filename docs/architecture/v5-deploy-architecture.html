ข้อจำกัด / สถานะ

  • Learner Lab ใช้ได้เฉพาะ us-east-1/us-west-2; V5 ใช้ us-west-2
  • IAM ถูกจำกัด: ใช้ LabMode=true, LabInstanceProfile/LabRole; ไม่สร้าง role
  • Amplify ถูกนำออกจาก V5; frontend ใช้ EC2/Docker + Caddy HTTPS
  • Cognito เป็น auth หลัก; local auth เป็น fallback ผ่าน AUTH_BACKEND=local
  • GitHub Actions ยังไม่รันเพราะไม่ push; cfn-lint/cfn-guard/drift ผ่านในเครื่องและ Lab
