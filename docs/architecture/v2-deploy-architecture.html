#ขั้นตอนรายละเอียด
1ผู้ใช้เปิดเว็บHTTPS ไปยัง Amplify ซึ่งรัน Next.js หน้า /stakeholders /documents /activities
2Proxy APINext.js rewrite /api/v1/* ฝั่ง server ไปยัง FastAPI บน EC2 port 8000 เบราว์เซอร์จึงเรียก API ผ่านโดเมน HTTPS เดียวกัน
3อ่านข้อมูลFastAPI query RDS PostgreSQL database cstu_demo สำหรับ list · detail · search · filter · relationship เฉพาะข้อมูลที่เผยแพร่
4ดาวน์โหลดเอกสาร/documents/{id}/download backend อ่าน PDF จาก S3 ด้วย IAM role ของ EC2 ไม่ส่ง credentials ให้ frontend
5Build & deploypush เข้า main บน GitHub → Amplify build และ deploy frontend อัตโนมัติ
