สถาปัตยกรรมการ deploy ระบบ V3

CS361 G650-15 · Collaboration Repository + ระบบสิทธิ์ผู้ใช้ · AWS ap-southeast-1 (Singapore)

#ขั้นตอนรายละเอียด
1เปิดเว็บHTTPS ไปยัง Amplify ซึ่งรัน Next.js ทั้งหน้าดูข้อมูล หน้า /login และฟอร์มเพิ่ม/แก้ไข
2Proxy APINext.js rewrite /api/v1/* ไปยัง FastAPI บน EC2 port 8000 หลัง sign in ทุกคำขอแนบ Authorization: Bearer <token>
3Sign in และตรวจสิทธิ์POST /auth/login ให้ backend ส่ง email/รหัสผ่านไปตรวจที่ Cognito (เบราว์เซอร์ไม่ได้คุยกับ Cognito ตรง) คำขอถัดไป auth.py ตรวจลายเซ็น token กับ JWKS ของ Cognito แล้ว require_role(...) ตามตารางสิทธิ์ V3 ไม่มี token → 401 บทบาทไม่พอ → 403
4อ่าน/เขียนข้อมูลFastAPI อ่านเขียน RDS PostgreSQL ผ่าน TLS ทุกการแก้ไขบันทึก audit_logs ใน transaction เดียวกัน ผู้ไม่มีสิทธิ์เห็นเฉพาะข้อมูลที่เผยแพร่
5เอกสาร PDFbackend อัปโหลดและแทนไฟล์ PDF บน S3 ด้วย IAM role ของ EC2 (role ยังไม่มีสิทธิ์ลบ) เอกสารสาธารณะดาวน์โหลดผ่าน backend ส่วนเอกสารภายในได้ presigned URL อายุสั้นไปโหลดจาก S3 ตรง ไม่ส่ง credentials ให้ frontend
6Build & deploypush เข้า main บน GitHub → Amplify build และ deploy frontend อัตโนมัติ

เพิ่มใน V3

  • เข้าสู่ระบบด้วย Amazon Cognito และสิทธิ์ตามบทบาท 5 ระดับ
  • เพิ่ม/แก้ไข/ลบ หน่วยงาน ข้อตกลง กิจกรรม การแลกเปลี่ยน
  • อัปโหลด PDF ผ่านเว็บ · audit log ทุกการแก้ไข

ยังไม่ได้ใช้

  • Load balancer, Auto Scaling, Multi-AZ
  • Elastic IP ของ EC2 (IP เปลี่ยนเมื่อ stop/start)
