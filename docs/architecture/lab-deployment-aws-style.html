Deployment · Lab environment · AWS style

Current lab architecture

One EC2 host, a Cloudflare tunnel, and local password auth, rendered in an AWS palette with service-style icons. Amplify, RDS, S3, and Cognito are still out of the request path.

Cost / lifetime

$0 now, but temporary

  • Lab credits cover the EC2 host and its EBS volume.
  • A lab reset can wipe the instance, database, and files.

Security

HTTPS only, demo auth

  • Cloudflare terminates TLS; the EC2 public HTTP port is closed.
  • Local auth has no MFA, password reset, or federation.

Data

One EBS volume

  • Postgres and uploaded files share the instance.
  • No RDS backups or S3 durability; the host is the single point of failure.
