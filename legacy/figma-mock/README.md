# figma-mock — Design-Team UI Prototype

UI prototype ชิ้นแรกของโปรเจกต์ สร้างโดยทีมดีไซน์ (Figma Make export) ใช้ Vite + React + TypeScript และข้อมูล mock ทั้งหมด (ไม่ต่อ API จริง)

เวอร์ชันระบบจริง (V1) พัฒนาต่อที่ `frontend/` (Next.js) — โปรเจกต์นี้เก็บไว้เป็น reference ของงานดีไซน์ต้นฉบับเท่านั้น ไม่ได้ใช้งานจริง

## วิธีรัน

```bash
cd legacy/figma-mock
pnpm install
pnpm dev
```
